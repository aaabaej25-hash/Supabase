# 디자인 요청서 (Design Brief)
### 서비스명(가칭): TubeNote — 유튜브 링크를 마크다운 문서로

> 유튜브 링크 → 마크다운 변환 서비스의 프론트엔드 디자인을 Claude 디자인에 위임하기 위한 요청서입니다.

---

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| **한 줄 설명** | 유튜브 링크를 붙여넣으면 영상 내용을 구조화된 마크다운 문서로 자동 변환해주는 웹 서비스 |
| **핵심 가치** | "영상 1시간을 5분 만에 읽는 문서로" — 자막/음성을 분석해 요약·목차·핵심 포인트가 담긴 문서 생성 |
| **타깃 유저** | 학습·리서치 목적으로 영상을 빠르게 소화하려는 지식 노동자, 학생, 콘텐츠 정리하는 크리에이터 |
| **플랫폼** | 데스크톱 우선 반응형 웹 (모바일 대응 필요) |
| **산출물** | 아래 5개 화면의 하이파이 UI 디자인 + 화면 간 전환 흐름 |

## 2. 디자인 톤 & 무드 (확정)

- **분위기:** **모던 & 비비드** — 선명한 그린 틴트, 큰 타이포, 시원한 여백과 과감한 대비. 트렌디하고 임팩트 있는 마케팅·프로덕트 톤
- **포인트 컬러:** **그린/틴트 계열** (예: `#10B981`~`#14B8A6` 에메랄드–틴트 스펙트럼)
  - 유튜브 레드와 명확히 구분되어 "별개의 신선한 도구"라는 인상
  - 그린은 변환 완료·성공 상태와도 자연스럽게 연결됨
- **베이스:** 뉴트럴(화이트/오프화이트 + 다크 그레이), 포인트는 그린 1색으로 절제
- **타이포:** 가독성 높은 산세리프(Inter / Pretendard), 히어로·헤드라인은 크고 굵게(비비드 무드 강조)
- **그래픽:** 그라데이션(그린→틴트), 부드러운 그림자, 라운드 코너, 가벼운 모션/마이크로 인터랙션 권장
- **다크모드:** 지원 (특히 문서 뷰어)
- **무드 키워드:** `선명한`, `시원한`, `빠른`, `신선한`, `읽기 편한`

## 3. 유저 플로우 (전체 흐름)

```
[1. 랜딩(소개)]
      │  "시작하기" CTA
      ▼
[2. 로그인] ──(인증 성공)──▶ [3. 대시보드]
                                   │
                                   │ 우하단 (+) FAB 클릭
                                   ▼
                            [3-1. 링크 입력 모달]
                                   │ 링크 입력 + 변환 시작
                                   ▼
                            [4. 로딩(변환 중)]
                                   │ 변환 완료
                                   ▼
                            [5. 문서 뷰어]
                                   │ "목록으로"
                                   ▼
                            [3. 대시보드] (새 문서가 카드로 추가됨)
```

## 4. 화면별 상세 요구사항

### 화면 1 — 랜딩 / 서비스 소개
- **목적:** 처음 방문자에게 "이게 뭐 하는 앱인지" 3초 안에 이해시키고 가입 유도
- **필수 요소:**
  - 상단 네비게이션 바 (로고 / 로그인 버튼)
  - 히어로 섹션: 강력한 헤드라인 + 서브카피 + 핵심 CTA 버튼("무료로 시작하기")
  - **제품 미리보기 비주얼:** "유튜브 링크 입력 → 마크다운 문서" 변환을 보여주는 일러스트 또는 목업
  - 핵심 기능 3가지 소개 섹션 (예: ① 자동 요약 ② 목차/타임스탬프 ③ 마크다운 내보내기)
  - 간단한 사용 흐름 3스텝(붙여넣기 → 변환 → 읽기/내보내기)
  - 푸터
- **무드:** 임팩트 있고 설득력 있게 (모던 & 비비드 강조)

### 화면 2 — 로그인
- **목적:** 최소 마찰로 진입
- **필수 요소:**
  - 중앙 정렬 카드형 레이아웃
  - **Google 소셜 로그인 버튼을 최상단·최강조**로 배치 (가장 큰 1차 액션)
  - 이메일/비밀번호는 그 아래 보조 영역으로 (구분선 "또는")
  - 회원가입 링크, 로그인 상태 유지 체크박스
  - 그린 포인트는 입력 포커스·기본 버튼·링크에 적용
  - 좌측 또는 배경에 브랜드 비주얼(선택)
- **상태 디자인:** 입력 에러, 로딩 버튼 상태 포함

### 화면 3 — 대시보드
- **목적:** 내가 만든 문서들을 모아보고 관리, 새 문서 생성
- **필수 요소:**
  - 좌측 사이드바 또는 상단 바 (로고, 내 계정, 메뉴)
  - 변환한 문서 **카드 그리드** (썸네일/영상 제목 / 생성일 / 채널명 / 짧은 요약 미리보기)
  - 검색 + 정렬/필터
  - **우하단 플로팅 (+) 버튼 (FAB)** ← 핵심. 클릭 시 링크 입력 모달 오픈
  - **빈 상태(Empty State) 디자인** 필수: 문서가 하나도 없을 때 "+ 버튼으로 첫 문서를 만들어보세요" 안내
- **카드 인터랙션:** hover 시 액션(열기/삭제/내보내기)

### 화면 3-1 — 링크 입력 모달
- **목적:** 유튜브 링크 입력받아 변환 시작
- **필수 요소:**
  - 모달 오버레이(딤 처리)
  - 유튜브 URL 입력 필드 (붙여넣기 강조, placeholder 예시 URL)
  - **입력 검증 피드백:** 유효한 유튜브 링크인지 실시간 표시, 유효 시 영상 썸네일/제목 프리뷰 노출
  - (선택) 변환 옵션: 요약 길이, 언어 등
  - "변환 시작" 기본 버튼 / "취소"
- **상태:** 빈 입력, 유효, 무효(에러), 로딩

### 화면 4 — 로딩 / 변환 중
- **목적:** 변환이 시간 걸림을 자연스럽게 안내해 이탈 방지
- **필수 요소:**
  - 진행 상태 시각화 (단계별 스텝퍼 권장: `영상 분석 → 자막 추출 → 요약 생성 → 문서 작성`)
  - 진행률 또는 애니메이션 인디케이터
  - 변환 중인 영상 정보(썸네일/제목) 표시
  - 예상 소요 시간 또는 안내 문구
  - (선택) 백그라운드 처리 후 대시보드로 돌아갈 수 있는 옵션
- **무드:** 기다림이 지루하지 않게, 신뢰감 주는 진행 표현

### 화면 5 — 문서 뷰어
- **목적:** 생성된 마크다운 문서를 읽기 좋게 보여주고 활용
- **필수 요소:**
  - 상단: 영상 제목 / 채널 / 원본 영상 링크 / 생성일
  - 좌측 또는 우측 **목차(TOC) 네비게이션** (긴 문서 대응)
  - 본문: 마크다운 렌더링 (제목, 리스트, 인용, 코드블록, 타임스탬프 링크 등)
  - 상단 액션 바: **복사 / 마크다운(.md) 다운로드 / 공유 / 원본 영상 보기 / 편집(선택)**
  - 읽기 폭 제한된 본문 레이아웃 (가독성)
- **무드:** 읽기 경험 최우선, 다크모드 특히 신경

## 5. 공통 / 글로벌 요구사항

- **반응형:** 데스크톱·태블릿·모바일 브레이크포인트 정의
- **상태 디자인:** 로딩 / 빈 상태 / 에러 / 성공 토스트 일관성 있게
- **디자인 시스템:** 컬러 팔레트, 타이포 스케일, 버튼·인풋·카드·모달 컴포넌트 정의
- **접근성:** 명도 대비, 포커스 상태, 키보드 내비게이션 고려
- **일관성:** 5개 화면이 하나의 제품으로 보이도록 통일된 컴포넌트/스페이싱

## 6. 산출물 & 우선순위

1. (필수) 5개 화면 + 모달 하이파이 디자인
2. (필수) 화면 전환 흐름이 드러나는 구성
3. (권장) 라이트/다크 모드
4. (권장) 핵심 컴포넌트 정리
