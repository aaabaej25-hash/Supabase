# EPUB 메이커 설계 문서

날짜: 2026-07-14
상태: 사용자 검토 대기

## 목표

DOCX 원고를 넣으면 디자인을 입힌 표준 EPUB 전자책이 나오는 브라우저 단독 앱.
결과물은 부크크 같은 자가출판 플랫폼에 등록하여 유통 가능한 수준이어야 한다.

**성공 기준**
- 생성된 EPUB이 EPUB3 표준 검사(epubcheck 규칙)를 통과한다.
- 일반 단행본 원고(소설·에세이·실용서: 텍스트 + 그림 + 표)가 상업 판매 수준의
  디자인으로 변환된다.
- 비개발자가 설치 없이 launch.bat 더블클릭으로 실행하고, 안내 없이도 흐름을
  따라갈 수 있다.

## 범위

**1차 버전에 포함**
- 입력: .docx (텍스트 위주 + 그림·표 포함 문서)
- 출력: EPUB3 파일 다운로드
- 테마 4종 + 세부 디자인 조정 + 실시간 미리보기
- 표지: 이미지 업로드 + 제목·저자 기반 자동 생성
- 유통용 책 정보(메타데이터) 입력
- EPUB 표준 자동 검사

**제외 (추후 버전)**
- PDF 입력 (구조 복원 품질 편차가 커서 2차로 연기)
- 종이책 인쇄용 PDF 출력 (POD 종이책)
- 구형 .doc 형식 (안내 메시지로 .docx 재저장 유도)
- 각주 다수·세로쓰기 등 고급 조판

## 기술 접근 (A안: 검증된 라이브러리 조립)

브라우저 단독 앱. 서버·설치 불필요, 완전 오프라인 동작.
essay_helper와 같은 구조(HTML/JS + launch.bat).

| 단계 | 담당 | 설명 |
|------|------|------|
| DOCX 파싱 | mammoth.js | 워드 "제목 1/2" 스타일을 시맨틱 HTML(h1/h2)로 변환, 이미지 추출 |
| 챕터 분할 | 자체 구현 | h1 기준으로 HTML을 챕터 단위로 분리 |
| 미리보기 | iframe + 테마 CSS | 조정할 때마다 즉시 반영 |
| EPUB 생성 | JSZip | EPUB3 구조(OPF, NCX/nav, XHTML, CSS, 이미지, 폰트)를 ZIP으로 조립 |
| 표준 검사 | 자체 검사기 | epubcheck 핵심 규칙(필수 파일, 매니페스트 일치, XHTML 유효성, 메타데이터 필수 항목)을 브라우저에서 검사 |

B안(DOCX XML 직접 파싱)은 개발량 대비 이득이 없어 기각.
EPUB은 리플로우 포맷이므로 원본 종이 레이아웃 재현은 목표가 아니다.

## 화면 구성

3패널 레이아웃, 상단에 3단계 진행 표시(문서 올리기 → 디자인 꾸미기 → EPUB 내려받기).

- **왼쪽 패널**: 책 정보(제목·저자·유통 정보), 표지 설정, 챕터 목록
- **가운데**: 전자책 미리보기 (선택한 챕터를 테마 적용 상태로 표시)
- **오른쪽 패널**: 테마 선택 + 세부 디자인 조정

## 사용 흐름

1. launch.bat 실행 → 브라우저가 열림
2. DOCX를 드래그 앤 드롭 → 파싱 → h1 기준 챕터 자동 분할 → 챕터 목록 표시
3. 책 정보 입력, 표지 업로드 또는 자동 생성 선택
4. 테마 선택, 세부 조정 → 미리보기 실시간 반영
5. "EPUB 만들기" → 자동 표준 검사 → 통과 시 다운로드
6. 디자인 설정·책 정보는 localStorage에 자동 저장 (원고 파일은 저장하지 않음)

## 테마와 디자인 조정

**테마 4종**
| 테마 | 특징 |
|------|------|
| 소설·에세이 | 명조체, 넉넉한 줄 간격(1.8+), 첫 줄 들여쓰기, 가운데 챕터 제목 |
| 실용·자기계발 | 고딕체, 또렷한 챕터 번호·제목, 들여쓰기 대신 문단 간격 |
| 클래식 | 전통 조판, 장식 구분선, 가운데 제목 |
| 미니멀 | 여백 강조, 장식 최소화 |

**조정 항목**
- 글꼴: KoPub 바탕/돋움 내장(기본) 또는 기기 기본 글꼴
- 글자 크기, 줄 간격, 문단 간격, 첫 줄 들여쓰기
- 본문 좌우 여백
- 챕터 제목: 정렬, 크기, 장식(구분선·번호 표기)
- 챕터 시작 방식(새 페이지 여부)

글꼴 내장 시 KoPub 라이선스 고지 파일을 EPUB에 포함한다.

## 표지

- 업로드: JPG/PNG. 플랫폼 권장 규격(세로형 비율, 최소 해상도) 검사 후
  미달 시 경고 표시(차단하지는 않음)
- 자동 생성: 제목·저자명을 테마 색감에 맞춰 배치한 표지 이미지를
  canvas로 생성

## 유통용 책 정보 (메타데이터)

- 필수: 제목, 저자, 언어(기본 ko)
- 선택: ISBN, 출판사명, 발행일, 책 소개
- EPUB OPF 메타데이터에 매핑. 필수 항목 미입력 시 EPUB 생성 버튼 비활성화 및 안내

## 오류 처리

| 상황 | 처리 |
|------|------|
| .doc(구형) 업로드 | ".docx로 다시 저장 후 업로드" 안내 (워드에서 저장하는 방법 포함) |
| 제목 스타일 없는 문서 | 단일 챕터로 변환 + "제목 1 스타일을 쓰면 챕터가 나뉩니다" 안내 |
| 텍스트 상자·다단 등 단순화된 요소 | 변환 직후 "단순화된 요소 목록" 표시 |
| 이미지 과다로 파일이 큼 | 전자책 적합 크기로 자동 압축 (원본 유지 옵션) |
| 표준 검사 실패 | 실패 항목을 한국어로 표시, 다운로드 차단 |
| 표지 규격 미달 | 경고 표시 (다운로드는 허용) |

## 구성 파일 (모듈 경계)

```
epub_maker/
  index.html        화면 뼈대
  style.css         앱 UI 스타일
  app.js            화면 배선·상태 관리
  docx-parser.js    mammoth 호출, 챕터 분할, 단순화 요소 수집
  themes.js         테마 4종 정의(EPUB용 CSS 생성)
  cover.js          표지 검사·자동 생성
  epub-builder.js   EPUB3 구조 조립(JSZip)
  epub-validator.js 표준 검사
  storage.js        설정 localStorage 저장·복원
  vendor/           mammoth.js, jszip (오프라인 동작용 로컬 복사본)
  fonts/            KoPub 바탕·돋움 + 라이선스 고지
  launch.bat        바탕화면 바로가기용 실행 파일
  tests/            단위 테스트
```

각 모듈은 한 가지 책임만 갖고, app.js만 화면(DOM)을 만진다.

## 테스트

- docx-parser: 챕터 분할(제목 스타일 유무), 이미지 추출, 단순화 요소 수집
- epub-builder: 생성된 ZIP 구조가 EPUB3 필수 요건을 갖추는지
- epub-validator: 정상/결함 EPUB 샘플 판별
- cover: 규격 검사 경계값
- 수동 검증: 생성 EPUB을 실제 epubcheck CLI와 리디북스 뷰어·Calibre로 열어 확인
